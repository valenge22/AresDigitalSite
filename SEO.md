# SEO de ARES Digital

## Página principal

- URL: `https://aresdigital.site/`
- Title: `Desarrollo Web y Software a Medida | ARES Digital`
- Description: `Desarrollo web, software a medida y soluciones digitales para empresas en Argentina. Creamos sitios, sistemas y herramientas para cada negocio.`
- Canonical: `https://aresdigital.site/`
- Robots: `index, follow, max-image-preview:large`
- Schema: `Organization` y `WebSite`
- Open Graph y Twitter/X: configurados con metadata coherente y un visual existente de producto.

## Indexación

- `robots.txt` permite rastrear el sitio y declara el sitemap.
- `sitemap.xml` incluye únicamente la página principal indexable.
- `gracias.html` usa `noindex, follow` y no forma parte del sitemap.

## Search Console y Bing

No hay tokens de verificación en el proyecto. Queda pendiente verificar `https://aresdigital.site/`; se recomienda una propiedad de dominio en Google Search Console si se dispone de acceso DNS. Bing Webmaster Tools puede configurarse después importando la propiedad verificada o mediante DNS.

## Comprobaciones pendientes en producción

- Confirmar redirección HTTP a HTTPS.
- Confirmar un único host canónico entre `www` y sin `www`.
- Comprobar la respuesta 404 publicada y enviar el sitemap en Search Console.
